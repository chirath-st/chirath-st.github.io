# chirath-st.github.io

Personal portfolio of **Chirath Soithong**: Data Science and Economics at Rutgers University–New Brunswick (expected May 2028).

Live site: **https://chirath-st.github.io**

- `/`: main site with four case studies (Agoda ×2, BuzzeBees, Rutgers Road to Silicon Valley)
- `/tech/`: technical edition of the same work

Built with Vite (multi-page, vanilla JS), GSAP ScrollTrigger and plain CSS. Works with JavaScript off and with reduced motion. Deployed by GitHub Actions to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```
